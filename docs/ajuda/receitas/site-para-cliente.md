# Criar um site para um cliente

## Passo a passo
1. **Peça tudo de uma vez.** Diga o cliente, o objetivo da página, o público, as seções e o repositório. A Yui monta uma missão com as etapas e os agentes.
   > Diga: "Yui, cria uma landing page para a Clínica Fisioforma no projeto fisioforma-site: serviços, depoimentos, WhatsApp e agendamento. Tom acolhedor."
2. **Confira o plano.** A missão abre em Missões com as etapas (ex.: Designer, Copy, Frontend, QA). Se faltar algo, peça para cancelar e refaça o pedido mais completo.
3. **Assista os testes.** Quando o QA testar, abra Ferramentas › Navegador para ver o site sendo usado.
4. **Veja o preview.** Em Projetos, abra o repositório e clique em Preview.
5. **Ajuste.** Peça mudanças pontuais à Yui; elas viram tarefas para o agente certo.
   > Diga: "No site da Fisioforma, troca a cor do botão principal para verde e aumenta a foto do topo."
6. **Publique com OK.** Push e deploy param em Aprovações. Leia o comando e aprove.
