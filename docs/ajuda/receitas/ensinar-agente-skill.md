# Ensinar um agente com uma skill do skills.sh

## Passo a passo
1. **Abra a ficha do agente.** Agentes › clique no agente.
2. **Busque.** Na seção "Skills do skills.sh", digite o assunto (ex.: tdd, seo, playwright).
3. **Confira.** Clique no nome para ler o SKILL.md e ver as auditorias.
4. **Adicione.** "Instalar em <agente>" — o agente já vem marcado; marque outros se quiser.
5. **Teste.** Use "Testar" no topo da ficha: o agente lista as skills que tem agora.
   > Diga: "Yui, instala a skill tdd no agente QA."
